# DVOR — 3D-конструктор кроссовок

> 3D-конфигуратор кроссовок вымышленного бренда DVOR (коллекция SS27). Выбираешь одну из четырёх моделей, настраиваешь материал и цвет каждой детали, разбираешь пару на компоненты, добавляешь надпись на пятку и оформляешь демо-предзаказ с печатающимся чеком.

## О проекте

Модель кроссовка вращается в центре экрана на фоне в стиле технического листа: линейка в миллиметрах, кроп-метки и крупный номер модели. Интерфейс копирует рабочий инструмент дизайнера обуви, а не витрину интернет-магазина.

## Коллекция

| № | Модель | Тип |
|---|---|---|
| 01 | **Двор** | кожаный кед |
| 02 | **Волна** | беговой концепт |
| 03 | **Твид** | скейтовый кед |
| 04 | **Раунд** | хайтоп |

Модели грузятся лениво. При смене модели старая пара разлетается на детали.

## Что внутри

- **Покомпонентная настройка.** От 9 до 13 зон на модель и 24 материала: кожа, замша, лак, рефлектив, пена, каучук, прозрачная резина «лёд», металлы, гель, хром, твид и другие. Материалы физически корректные (PBR с clearcoat, sheen, transmission и iridescence), процедурная фактура добавлена через `onBeforeCompile`.
- **«Разобрать» (`E`).** Пара разлетается на детали по GSAP-таймлайну. Направления считаются от центроидов деталей, у каждой появляется выноска с подписью.
- **Надпись на пятке.** Сделана через `DecalGeometry` и `CanvasTexture`, на выбор фольга (золото или серебро), тиснение или печать.
- **Живые характеристики.** Цена и вес пересчитываются на лету, у материалов есть шкалы «мягкость / прочность / лёгкость», размерная сетка EU / US / см.
- **Фишки.** Готовые расцветки, «Удиви меня» (`R`), смена ракурсов, «Вспышка», от которой светятся рефлективные детали.
- **Предзаказ.** Чек «печатается» из принтера с номером заказа `DV-XXXX`. Конфигурация хранится в URL-хэше, ссылкой можно поделиться.
- **Работает без сервера.** Модели продублированы как base64-модули (`assets/models/*.js`), поэтому страница открывается даже через `file://`. На мобильных облегчённый рендер, учитывается `prefers-reduced-motion`.

## Стек

Three.js 0.186 (import map) · GLTFLoader + MeshoptDecoder · DecalGeometry · RoomEnvironment / PMREM · кастомные шейдеры · GSAP 3.15 · vanilla JS

## Запуск

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000. Через сервер модели `.glb` грузятся с настоящим прогрессом загрузки. Можно и просто открыть `index.html` двойным кликом: страница переключится на встроенные копии моделей. Нужен интернет, потому что библиотеки грузятся с CDN.
